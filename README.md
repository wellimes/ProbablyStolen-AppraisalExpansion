# 深空鉴定拓展 / Appraisal Expansion

《Probably Stolen》（深空当铺：可能是偷的）的社区 Mod —— 在原版「鉴定物品」系统基础上，扩展出一整套**拾荒 → 鉴定 → 对质 → 供货 → 倒卖**的玩法闭环。

> A community mod for *Probably Stolen* that expands the appraisal / pawn-shop gameplay:
> scavenging, authenticity inspection, supplier networks, night shops and customer demand.

**当前版本：v0.3.0** · 游戏版本：`0.46D` · 许可证：MIT

## 功能总览

| 模块 | 内容 |
|---|---|
| 拾荒掉落 | 夜晚拾荒可捡到机械手 / 肋排三明治 / 等离子燃料，赝品次品为主、正品稀有 |
| 放大镜对质 | 逐项核对物品属性、指控问题；指控正确揭穿打折，错误扣声望 |

| 委员会排期 | 加入鉴定委员会 + 证书放入展示栏过夜才吸引供货商；第 14 天六人齐到，之后每周随机一名 |

| 杰克逊夜店 | 夜间购买无标识等离子燃料，随进度解锁高级违禁品原料与制作机器 |

## 拾荒掉率

Mod 把自定义掉落表 `scav_appraisal_table` 挂进原版拾荒掉落组 `dumpingGroundTG`（组内权重 30 / 原版 1000）。

| 物品 | 每次拾荒概率 |
|---|---|
| 机械手 `scav_hand` | **1.29%** |
| 肋排 `scav_ribwich` | **0.97%** |
| 等离子 `scav_plasma` | **0.65%** |
| 合计 | ≈ 2.9% |

命中后表内权重为 机械手 40 / 肋排 30 / 等离子 20（约 44% / 33% / 22%）。

### 品质分布（越完好越稀有）

| 物品 | 品质分布 |
|---|---|
| 机械手 | 豪华 1% · 战术 3% · 高级 5% · 战斗 11% · 次品(随机) 40% · 次品(磨损/损坏) 40% |
| 肋排 | 双份肉 2% · 豪华 8% · 普通 20% · 次品(开封) 20% · 赝品(假货) 50% |
| 等离子 | 点火实验室 3% · 中华 8% · 共和国 8% · LL 21% · 次品/赝品(无标识等) 60% |

## 供货商与上门排期

### 六位供货商

| 供货商 | 电话 | 出售 |
|---|---|---|
| 三明治供货商 | 55521 | 肋排三明治 |
| 机械手供货商 | 55522 | 机械手 |
| LL 等离子供货商 | 55523 | LL 封条等离子 |
| 中华等离子供货商 | 55524 | 中华封条等离子 |
| 共和国等离子供货商 | 55525 | 共和国封条等离子 |
| 点火实验室等离子供货商 | 55526 | 点火实验室封条等离子 |

每位供货商有独立「合作额度」：买谁的货涨谁的额度，额度 ≥ 300 解锁高级档（更好的品质 + 更全的货）。

### 上门条件（重要）

供货商**不会**按固定星期出现，需同时满足：

1. 玩家**已加入鉴定委员会**（`isAppraisalIntroduced`）；
2. 玩家把**鉴定证书放进左侧展示栏并过夜**（在入睡时检测）；
3. 时间条件：
   - 从**初次拿到证书当天**起算，**第 14 天六位供货商一起上门**（唯一固定时间）；
   - 此后**每周（每 7 天）必定有且只有一名随机供货商**上门。

## 名片与电话

- 供货商到店时会给玩家一张 **1×2 格子名片**，号码印在名片上（点击名片可查看号码）。
- 电话本**不会**一开始就出现供货商。玩家需要**手动拨打**名片上的号码，接通后该号码才会保存进电话本。
- 未拿到名片（未拨过号）时，无法直接联系。
- 拨通后选择「好的，明天过来」，可让该供货商**下一游戏日**上门。

> 老存档首次载入会把旧版"直接可见"的联系人重置为"未解锁"状态（一次性迁移）。

## 放大镜对质

三种物品都可以用**放大镜**查看状态（原版 `INSPECTABLE_TAG` + 各自查看 UI），并支持**对质**：

| 物品 | 可指控的问题项 |
|---|---|
| 机械手 | 磨损 / 损坏 / 接口未标注 |
| 肋排 | 假货 / 已开封 |
| 等离子 | 裂纹 / 磨损 / 劣质颜色 / 螺丝裸露 |

### 判定与价格

- **拾荒/小偷带来的"有问题"物品**：显示**虚高的基础价**（100 / 150 / 300）。
- 玩家用放大镜核对后指控问题项：
  - **指控正确**：揭穿 → 价格改为**真实价值**，并再打 **85 折**（−15%）。
  - **指控错误**：扣声望。
- **供货商 / 杰克逊 / 拾荒捡到的正品**：价格始终等于真实价值（诚实价），无需对质。

夜间前往杰克逊博士的店铺（原版 `dr_jackson`），会自动补充以下商品：

| 条件 | 商品 |
|---|---|
| 始终 | 2 份「无标识等离子燃料」（`PLASMA_SEAL=NONE`，无封条溢价，杰克逊博士自制） |
| 第 20 天起 | 1 份「等离子原料（自制）」——**已打高级违禁品标签**（CONTRABAND_LEVEL_HIGH） |
| 第 40 天起 | 1 台制作机器（当前用原版能量转换器占位，后续替换专属机器） |

## 安装

### 方式一：手动安装（本地 Mod）

1. 下载 [dist/appraisal_expansion_v0.3.0.zip](dist/appraisal_expansion_v0.3.0.zip) 并解压；
2. 把解压出的 `appraisal_expansion` 文件夹放到：
   ```
   <游戏安装目录>\Mods\appraisal_expansion\
   ```
   目录内应包含 `manifest.xml`、`AppraisalExpansion.dll`、`LootTables\scav_appraisal.json`；
3. 启动游戏 → 主菜单「模组」→ 启用「深空鉴定拓展」。

> 建议开新档测试；旧档会触发一次性电话迁移。

## 从源码构建

需要 Windows 自带的 .NET Framework `csc.exe`（C# 5 编译器），**无需安装 .NET SDK**。

```bat
set "GAME_DIR=<游戏安装目录>"
set "M=%GAME_DIR%\Probably Stolen_Data\Managed"
"%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe" -nologo -target:library -langversion:5 -codepage:65001 ^
  -out:mod\AppraisalExpansion.dll ^
  -r:"%M%\netstandard.dll" ^
  -r:"%M%\System.Runtime.dll" ^
  -r:"%M%\Assembly-CSharp.dll" ^
  -r:"%M%\Assembly-CSharp-firstpass.dll" ^
  -r:"%M%\UnityEngine.CoreModule.dll" ^
  -r:"%M%\0Harmony.dll" ^
  -r:"%M%\UnityEngine.UI.dll" ^
  -r:"%M%\Unity.TextMeshPro.dll" ^
  src\AppraisalExpansion.cs
```

或直接双击仓库根目录的 [`build.bat`](build.bat)（记得先改里面的 `GAME_DIR`）。

> ⚠️ 旧版 `csc` 存在重载解析问题，以下调用必须带额外参数：
> - `DirectoryMaster.Item("x", true)`
> - `ModifyTag("x", ..., false)`
> - `EnableTag("x", false)`

## 常见问题

**Q：进了游戏但没看到任何供货商？**
A：需要先加入鉴定委员会，并把鉴定证书放进左侧展示栏过夜；第 14 天才会有六人齐到，之后每周一名。

**Q：电话本里没有供货商？**
A：电话本默认隐藏，必须先手动拨打名片上的号码，接通后才会保存。

**Q：拾荒一直捡不到三种物品？**
A：概率约 2.9%，属于稀有掉落；可在 `LootTables/scav_appraisal.json` 调高组内权重。

**Q：价格和描述对不上？**
A：供货商/杰克逊的货是诚实价；拾荒捡到的"有问题"物品才是虚高基础价，对质成功后会变成真实价并打折。

**Q：旧存档能用吗？**
A：可以，但首次载入会重置供货商电话为未解锁状态（一次性迁移）。
